8 projetos. Uma nota para cada.

Equipes de estudantes apresentam, em 5 a 7 minutos, soluções web para comunidades locais de Manaus. Os empresários convidados avaliam cada projeto com seis critérios e a nota final vai de 0 a 10.

Como a nota é composta

Seis critérios, uma nota geral

Cada avaliador dá uma nota de 0 a 10 (de meio em meio ponto) para cada critério.

    Nota do projeto = média dos seis critérios de cada avaliador, e depois a média entre os avaliadores. O resultado fica entre 0 e 10.
